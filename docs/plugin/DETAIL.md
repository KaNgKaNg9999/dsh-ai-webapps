# DeepSeek 网页面板（dsh-ai-webapps）

> 状态：草案（2026-11-26）｜M0 六项验收通过后转定稿
> 本文件是插件详情页正文（`meta.detail` 指向此处）。

## 这个插件做什么

在 DSH 桌面端的左栏加一个 **DeepSeek** 入口，点开后在主面板里显示 DeepSeek 网页版聊天（Electron `<webview>`）：

- 全宽聊天，不用切到浏览器；
- 切到会话、插件页再切回来，**页面不重载**（草稿与滚动位置保留）；
- 登录一次后，**同一台机器重启 DSH 自动恢复登录**（站点自己过期才需重登）。

## 怎么用

1. 安装插件后，左栏出现 **DeepSeek** 行；点击进入主面板。
2. 首次进入在面板里正常登录（手机/邮箱 + 验证码）。
3. 之后照常使用；登录态会自动保存到本机。
4. 需要清掉登录态时：**设置 → 站点** → 清除已保存登录。

## 已知限制

- 仅 DSH **桌面端**可用；Web 版会提示需要桌面端。
- **每台机器各自登录一次**：登录态不跨机器迁移（站点有设备校验）。
- 下载文件、麦克风/摄像头、桌面通知、读取剪贴板不可用（宿主对嵌入页面收紧权限）。
- 站点通过 `about:blank` 打开的弹窗会被拒绝；HTTP(S) 弹窗改为在系统浏览器打开。
- 登录态以明文保存在本机 DSH 页面的 localStorage（等同浏览器的 Cookies 文件），设置页可清除。
- 嵌入能力依赖 DSH 内部接口，DSH 升级后可能需要跟随适配。

## 卸载

在 **插件** 页面移除本插件即可；残留仅本机 localStorage 中的两个键（站点表与登录快照），可在设置页清除。
