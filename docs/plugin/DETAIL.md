# DeepSeek 网页面板（dsh-ai-webapps）

> 状态：定稿（2026-11-27，对应 1.0.0）｜本文件是插件详情页正文（`meta.detail` 指向此处）。

## 这个插件做什么

在 DSH 桌面端左栏加一个 **DeepSeek** 入口，点开后在主面板里显示 DeepSeek 网页版聊天（Electron `<webview>`）：

- 全宽聊天，不用切到浏览器；
- 切到会话、插件页再切回来，**页面不重载**（草稿与滚动位置保留）；
- 登录一次后，**同一台机器重启 DSH 自动恢复登录**（站点自己过期才需重登）；
- 出问题不用开发者工具：设置页有「诊断」卡，能看状态与最近日志。

## 怎么用

1. 安装插件后，左栏出现 **DeepSeek** 行；点击进入主面板。
2. 首次进入在面板里正常登录（手机/邮箱 + 验证码，站点若弹图片选择验证码按提示点）。
3. 顶部工具栏：**刷新** / **在系统浏览器打开** / **复制链接** / **清除登录**。
4. 设置路径：**设置 → DeepSeek 网页**。
   - **面板位置**：左栏行 → 主面板，可一键「打开面板」；
   - **站点**：只读地址 + 复制；
   - **登录快照**：状态胶囊、保存时间、localStorage 键数、cookie 条数、大小、跳过/截断，「立即保存」「清除已保存登录」；
   - **桌面桥**：显示是否可用与协议版本；
   - **诊断**：阶段、容器 lease、站点主机、登录回填、崩溃次数、快照状态，最近 100 条日志，「复制诊断信息」「清空日志」；
   - **已知限制**：见下。
5. 换机器或想重新登录：设置页「清除已保存登录」，再在面板里登录一次。

## 排障

- 面板出问题先看 **设置 → DeepSeek 网页 → 诊断**：
  - `guest attached; lease=…` 表示 webview 已建立；
  - `snapshot injected` / `backfill restored sign-in` 表示登录快照已恢复；
  - `guest gone` / `guest crash limit reached` 表示崩溃与自动重建用尽（此时面板给「刷新重试」按钮）。
- 「复制诊断信息」只包含状态、键名与**已脱敏**日志：token / cookie / Authorization / 站点用户标识（UUID）都会打成 `***`，可以直接贴给维护者。
- 日志只在内存里（200 条上限），DSH 重启即清空。

## 已知限制

- 仅 DSH **桌面端**可用；Web 版会提示需要桌面端。
- **每台机器各自登录一次**：登录态不跨机器迁移（站点有设备校验）。
- 下载文件、麦克风/摄像头、桌面通知、读取剪贴板不可用（宿主对嵌入页面收紧权限）；站点弹窗改为在系统浏览器打开。
- 登录态以明文保存在本机 DSH 页面的 localStorage（等同浏览器的 Cookies 文件），设置页可清除；站点标识在诊断里已脱敏，但快照本身仍含登录凭据。
- 内嵌页面的开发者工具在打包版关闭；排障看设置页诊断卡（需要执行 JS 的深度取证另走调试端口，属临时手段）。
- 嵌入能力依赖 DSH 内部接口（桌面桥 `protocolVersion: 1`、Slot 契约），DSH 升级后可能需要跟随适配。

## 验证状态（2026-11-27）

- **M0 六项**：面板加载、登录成功、切面板不重载、快照键名核对（含 `userToken`）、同机重启自动登录、启动不自动停在站点面板 —— 全部通过。
- **M1 五项**：`[aiwa]` console 转发（前缀/级别正确）、stale 降级（坏 token 落 `stale` + 工具栏提示 + 无循环刷新）、崩溃重建（新 lease、免重登；不可见时只释放不重建）、弹窗层级（设置弹窗/右键菜单压在 guest 之上）、Turnstile（**未出现**；站点图片验证码可正常通过，不做 UA 覆盖）—— 全部通过；期间修复两处缺陷（`validateBackfill` 只看 token 键、`maybeStart` 卡在 `crashed` 态）。
- **收尾取证**：回填后 `POST /api/v0/users/auth_token/check_device → 200 {"code":0}`，设备校验放行；面板选中态不跨重启持久（DSH 布局状态 reload 即重置）。

## 卸载

在 **插件** 页面移除本插件即可；残留仅本机 localStorage 中的两个键（站点表与登录快照），可在设置页清除。

## 安装（给分发者）

- 本地目录：插件管理器 **Add plugin** 选目录，或 `plugin_manager` 的 `install_bundle` 指向绝对路径。
- GitHub 仓库（无需发 npm）：**Add plugin** 填 `git+https://github.com/<owner>/dsh-ai-webapps.git#<40 位 commit>`，或 `github:<owner>/dsh-ai-webapps#<40 位 commit>`。固定完整 commit 才能在插件页看到 git 更新；装 branch/tag 的只能卸载重装。
