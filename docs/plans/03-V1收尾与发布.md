补充事实（2026-11-27 核实 DSH 0.2.2-rc.5 实现，供 T7 使用）：

- `install_bundle` 接受 pnpm spec：包名[版本]、**Git 地址**（`github:owner/repo#<sha>` / `git+https://…`）、tarball、绝对本地目录。
- GitHub 仓库在 pnpm 之前先跑 `git ls-remote`（默认 5s 超时）；git / tarball 的 `engines.dsh` 兼容性**装完才判**，不满足则回滚 profile。

- 官方 Discover 是索引驱动（默认无索引）；format 1 索引的版本可用 `source.type: "git"` + commit（可选 `path`），安装参数与手填 git spec 等价。
- 第三方 `dshmarket` 只允许其策展目录（awesome-dsh-plugin）内的来源；该目录本身也是 format 1 索引，可加进 Discover。

## T1 诊断面板（对应 P0-2）

**现状**：排障只能靠宿主 console，而打包版 DevTools 打不开；`tools/cdp-eval.mjs` 是临时手段（要带调试端口重启，属取证用，不能常开）。即 `spec §10` 所说「转发虽正确，但人看不到」。

**做什么**：在 Client 内加一个内存环形日志缓冲 + 一套脱敏规则，并在设置页新增「诊断」卡展示 guest 状态与最近日志，提供「复制诊断信息 / 清空」。不引入 Host 能力、不写文件（D1 选 A 时）。

**怎么做**

1. **设计先行**（不写代码）：`docs/reference/architecture.md` 加「可观测性」小节（缓冲、脱敏、展示位置、容量），`docs/reference/v1-deepseek-spec.md` 加「日志与诊断」小节；两处都写清「为什么不落地到文件」。
2. **缓冲**：`createLogBuffer(limit = 200)` → `{ ts, level, scope, text }`，`push` 时超限丢最旧；`scope ∈ {'host','guest'}`；提供 `list()` / `clear()` / `subscribe(fn)`。
3. **统一入口**：`log(level, fmt, ...args)` 替代 40 处 `console.log/warn/error`（**保留原 console 输出**，行为不变）；`redact(text)` 规则：
   - URL query：`([?&][\w.-]+=)[^&\s]+` → `$1***`；
   - 敏感键值：`(token|authorization|cookie|password|userToken)\s*[=:]\s*\S+`（忽略大小写）→ `$1=***`；
   - 单行 >240 字符截断加 `…`。
4. **guest 日志**：`forwardConsole` 改走 `log(level, '[guest] %s', message)`（scope=`guest`），前缀统一在格式化时加 `[aiwa]`。
5. **暴露诊断**：`host.diagnostics()` 返回 `{ phase, leaseShort, urlHost, crashes, suspended, backfill, stale, keys, savedAt }`（**只有键名/状态/计数，无值**）；`controller.diagnostics()` / `controller.logs()` 透传。
6. **设置页**：新卡「诊断」——一行状态（阶段 / lease 前 8 位 / 主机名 / 崩溃次数 / 快照状态）+ 最近 100 条等宽日志（`max-height:220px` 可滚动，时间 `hh:mm:ss`，级别用 `--dsw-alias-state-*` 着色）+「复制诊断信息」「清空」。面板未打开时也能看（日志是启动期就在攒的）。
7. **文案**：`zh`/`en` 各加 ~8 键（`diagTitle`/`diagPhase`/`diagLease`/`diagCrashes`/`diagLogs`/`diagCopy`/`diagCopied`/`diagClear`/`diagEmpty`）。

**验收标准**

- [x] 正常启动后，**不开 DevTools**：设置 → DeepSeek 网页 → 诊断，能看到 `client ready` / `guest attached; lease=…` / `snapshot …` 等启动日志，时间戳正确。（2026-11-27 实测：`10:59:43 [aiwa] client ready; bridge=ok protocol=1`，随后 `guest attached`、`guest dom-ready`、`snapshot saved`。）
- [x] 制造一次崩溃：诊断卡出现 `guest gone: render-process-gone: unknown` → 600ms 后 `guest attached`（**新 lease** `20affc27-…`）→ 回到聊天页。注入用 CDP `Page.crash`（`tools/cdp-eval.mjs crash`），比外部杀进程更省事。
- [x] 脱敏可验证：真机 guest 日志中的 `user_unique_id` / `web_id` 在诊断里显示为 `***`；键名里的 UUID（如 `__appKit_..._<uuid>_userStorage`）也被打码；离线用例覆盖 `token=`、query、`Authorization`。
- [x] 「复制诊断信息」复制出的文本**不含**任何 localStorage/cookie 值：实测 13 行，无 UUID、无敏感值，表头只有 phase/lease 前 8 位/host/backfill。
- [x] 清空后列表为空并显示空态提示；卸载清理走既有 `ctx.effect`。
- [x] `node --check client.js` 通过；中英文案齐全（72 键）。

**风险与回滚**：替换 console 调用点属机械改动，但删漏会导致「日志变少」→ 改动前后各启动一次，对比关键事件行数；单 commit 可 revert。缓冲只存内存，无隐私落盘。

## T6 可测性：`node --test`（对应 P1-6）

**怎么做**

1. **抽纯函数（行为不变）**，直接在 factory 内定义、由调用点调用：
   - `decideBackfillProbe({ token, login, path })` → `'valid' | 'retry' | 'stale'`（封装 M1 修的 `login` 判据与 1s 复核条件）；
   - `decideSnapshotCollect({ login, token, existing, keys })` → `'skip-signin' | 'skip-notoken' | 'collect'`；
   - `decideRestart({ crashes, max, visible, disposed, starting, phase })` → `'restart' | 'defer' | 'stop'`；
   - `filterSnapshotValues(entries, { single, total })` → `{ entries, skipped, truncated }`；
   - `countCookies(str)`、`redact(text)`、`formatSize(n)`、`serializeInject(site)`（复用 `buildInjectScript` 的序列化部分）；
   - `resolveLocaleKey(dicts, key)` 不必抽；键对齐用测试直接解析源码（见 3）。
2. **暴露测试面**：模块返回值加 `__test: { …上述函数… }`（宿主只读 `inject`/`apply`，未知字段被忽略）；不新增全局变量。
3. **测试环境** `test/loader.mjs`：伪造 `window.__ModuleLoader__.load`、`require('react')` 返回最小 stub、`localStorage` 内存实现、`document` 最小 stub，加载 `client.js` 拿到 `{ factory }` 与 `__test`。
4. **测试用例**（`node --test test/`，零依赖）：
   - `locale.test.mjs`：解析 `client.js` 中 `zh`/`en` 两块字典 → 60 键对齐、值非空、无中文字符残留进 en；`locale/*.json` 可解析且 `meta.detail` 指向存在的文件。
   - `snapshot.test.mjs`：单值 >64KB 跳过计数、总量 >512KB 截断、`countCookies('a=1; b=2;')===2`（M1 的「209 实为长度」回归）、键名列表不含值。
   - `backfill.test.mjs`：坏 token（有键在、login=true）→ `stale`；token+login 首次 → `retry` 一次；有效 → `valid`。
   - `crash.test.mjs`：可见崩溃 → `restart`；不可见 → `defer`；crashes 超 3 → `stop`；`disposed` → 不重建；`crashed` 相位允许重建（M1 修复回归）。
   - `redact.test.mjs`：`token=abc`、`?a=1&b=2`、超长行 → 断言无原文、有 `***`。
5. **门禁更新**：`docs/CODING.md §2/§5` 加 `node --test test/`；`docs/agent/project.md` 命令段加同一条。
